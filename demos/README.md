## eviction/

The eviction defense demo — a 10-minute live demonstration showing:

- A nontechnical attorney built this in days for $0
- Live statute retrieval via Legal Data Hunter (not training-data guessing)
- Rules-grounded defect detection vs. raw LLM output — side by side
- CA → TX portability in one jurisdiction switcher click
- What the community needs to build next (the gaps)

**Contents:**

| File | What it is |
|------|-----------|
| `slides/Demo_Deck_v0.1.pptx` | 10-slide pitch deck (problem → what changed → demo → gaps → ask) |
| `prompts/demo-script.md` | Pre-written Cowork prompts to paste during the live demo; timing guide; contingency notes |
| `widget/RulesComparisonWidget.html` | Standalone browser widget — open in Chrome, no server needed |
| `widget/RulesComparisonWidget.jsx` | React component version for embedding |

**To run the demo:** Open [prompts/demo-script.md](eviction/prompts/demo-script.md) and follow the setup and beat instructions.
